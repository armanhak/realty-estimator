# Система оценки недвижимости

Веб-сервис рыночной оценки квартиры в Нижнем Новгороде.
Метод — локальная взвешенная регрессия логарифма цены по 14 признакам.
База: `data/apartments.xlsx` (выгрузка 1000 квартир от 18.11.2026, без строки заголовков; имена колонок задаются в `data_processor.py`).

## Локальный запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется `http://localhost:8501`.

## Деплой на Streamlit Cloud

1. Залейте проект на GitHub (вместе с `data/apartments.xlsx`).
2. Откройте https://share.streamlit.io и войдите через GitHub.
3. New app → репозиторий, ветка `main`, файл `app.py`.
4. Deploy. Ссылка будет вида `https://your-app-name.streamlit.app`.

## Что на экране

- Форма: площадь, комнаты, этаж, этажность, тип этажа, ремонт, материал, год, балкон, санузел, расстояние до центра, зона, остановка, метро.
- Рыночная стоимость и диапазон по разбросу цен аналогов.
- Водопад вклада факторов (условная денежная шкала).
- Топ-5 аналогов из базы с адресом, ценой и процентом сходства.

## Калибровка

Ширина гауссова окна — `bandwidth=1.5` в `ValuationModel` (`model.py`).
Меньше значение — уже круг аналогов, больше — шире.
