# Оценка квартир в Нижнем Новгороде

Веб-сервис из сборки в документе «КВЕН. Все коды»: страница с адресом дома, формой квартиры, таблицей поправок и ближайшими аналогами.

База: `data/apartments.xlsx`.

## Запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000

## Как пользоваться

1. Введите адрес — появятся подсказки из базы. Кнопка «Загрузить характеристики» подставит год, материал, этажность и расстояния.
2. Уточните площадь, комнаты, этаж и ремонт.
3. Нажмите «Рассчитать рыночную стоимость».

На экране: цена и диапазон, таблица поправок, ближайшие аналоги.

## Что заложено в расчёт

Цена описывается мультипликативной моделью. Перед сравнением признаки приводятся к одному масштабу. Вес аналога — гауссово ядро от расстояния в этом пространстве. Ширина окна: `bandwidth=1.5` в `model.py`.

Локация в модели — колонка «Функциональная зона». Колонка «Зона» в выгрузке почти везде пустая.
