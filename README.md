# Оценка квартир в Нижнем Новгороде

Вторая версия калькулятора: адрес дома, подстановка характеристик из базы, локальная взвешенная оценка, таблица поправок и ближайшие аналоги.

База: `data/apartments.xlsx`.

Ветка `main` этого репозитория — более ранняя версия без поиска дома. Эту ветку публикуйте отдельным приложением Streamlit: тот же репозиторий, ветка `streamlit-v2`, файл `app.py`.

## Запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Откроется http://localhost:8501

## Как пользоваться

1. Введите адрес и выберите подсказку. Кнопка «Загрузить характеристики» подставит год, материал, этажность, зону и расстояния.
2. Уточните площадь, комнаты, этаж и ремонт.
3. Нажмите «Рассчитать рыночную стоимость».

## Что заложено в расчёт

Цена описывается мультипликативной моделью. Перед сравнением признаки приводятся к одному масштабу. Вес аналога — гауссово ядро от расстояния в этом пространстве. Ширина окна: `bandwidth=1.5` в `model.py`.

Локация в модели — колонка «Функциональная зона». Колонка «Зона» в выгрузке почти везде пустая.
